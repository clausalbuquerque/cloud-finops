# AI Agents for Analysis

AI agents designed to analyze cloud consumption data and identify possible cost optimizations.

## Structure

- `agents/` – Agent definitions and orchestration logic
- `tools/` – Tools and functions available to agents
- `prompts/` – Prompt templates
- `tests/` – Unit and integration tests
- `docs/` – Documentation
- `python/` – Python services for retrieval/embedding runtime and tests
